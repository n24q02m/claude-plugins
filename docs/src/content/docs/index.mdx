## What is this?

A curated stack of MCP (Model Context Protocol) servers for Claude Code, Codex, Gemini CLI, Cursor, and Windsurf — sharing one foundation library ([`hull`](https://github.com/n24q02m/hull)) and one plugin marketplace (`n24q02m/claude-plugins`).

Servers are available through the Claude Code marketplace and npm or PyPI packages. Container availability and authentication requirements vary by server; see its setup guide for the supported distribution.

## Why these and not just any MCP server?

- **One foundation, seven consumers**: every active server (wet, mnemo, crg, telegram, notion, email, workspace) reuses `hull`'s HTTP transport, token auth, encrypted credential storage, and CLI built-ins. No bespoke auth code per server.
- **Multi-user when you need it**: HTTP `multi` auth gives every user their own bearer token and credential namespace. Self-host once, share with a team.
- **Composite tools, not raw API mirrors**: each server's tool list is curated for AI-agent ergonomics — fewer round-trips, less prompt clutter.
- **Production-grade releases**: signed Docker images, semantic-versioned packages, automated CI (CodeQL, secret scanning, push protection, Dependabot).
